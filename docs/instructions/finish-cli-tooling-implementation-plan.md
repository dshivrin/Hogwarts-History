# Finish CLI Tooling Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish the CLI tooling integration so every hot runtime entrypoint sends routine agents through `just` recipes instead of raw script paths.

**Architecture:** The root `Justfile` is now the stable command surface. `runtime-contract.md`, generated `project-control/next-run.md`, and the tests that protect them must all agree on the same workflow: use `just brief`, `just search`, `just query-dupes`, `just query-entries`, `just validate`, and `just post`. The generator `scripts/update_next_run.py` must emit the new guidance so `just brief` never regenerates stale raw-script instructions.

**Tech Stack:** Python 3, PyYAML, `unittest`, Markdown, `just`, `rg`.
