# Token Usage Scale-Up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reduce routine extraction overhead so each run spends tokens on source analysis and can cover more Hogwarts History source units over time without deleting, compressing, or weakening the durable evidence record.

**Architecture:** Keep `Justfile` as the stable command surface, add small Python helpers for structured YAML state, and make the hot runtime path start from a compact machine-produced brief. Efficiency comes from pointer-first access: keep all archival YAML and generated outputs intact, query compact indexes for IDs and paths, and open full evidence files only when a query result points to them. Do not make agents parse YAML with shell commands, do not depend on `yq`, and do not move source YAML or generated appendix paths in this pass.

**Tech Stack:** Python 3, PyYAML, `unittest`, Markdown, `just`, `rg`, existing project scripts.

---

## Success Targets

- A routine run starts with `just brief`, `just extract-current`, and targeted `just query-*` commands.
- The hot orientation output is under 60 lines and does not dump broad generated files.
- The measured hot-control budget protects `just brief` output, `runtime-contract.md`, and generated `next-run.md` from line-count drift.
- A routine agent reads only the runtime contract, compact state/brief, current extracted text, and current output YAML if it exists.
- Duplicate and context lookup happens through query recipes before any historical YAML file is opened.
- Validation and regeneration remain one-command operations through `just post`.
- The project can later support more than one source unit per session without weakening per-unit validation.
- No source YAML, generated appendices, generated book seed content, PDF source paths, or schema fields are removed for token savings.

## Efficiency Model: No Data Loss

This plan reduces token usage by changing what routine agents read, not by reducing what the project stores.

Preserve the durable data exactly where it already lives:

- `sources/book-*/*.yaml` remains the full chapter-level evidence archive.
- `book-seed/hogwarts-a-history-seed.md` remains the main generated human-readable result.
- `appendix/generated/*.md` remains generated review/support output.
- `project-control/*.yaml` remains the structured project state and compact lookup layer.
- PDFs remain untouched.

Make normal runs cheaper through pointer-first access:

1. `just brief` prints the current source unit, page range, output path, next unit, and command hints.
2. `just extract-current` turns `processing-state.yaml` into the extraction command without making the agent spend tokens reconstructing it.
3. `just query-dupes` and `just query-entries` return entry IDs, scores, tags, notes, and YAML paths from compact indexes.
4. The agent opens a historical YAML file only when a query result identifies it as a likely duplicate or useful corroboration.
5. `just hot-context` enforces budgets on orientation files so the hot path cannot drift back into broad reading.

Data is preserved; only the default read path changes.

```python
#!/usr/bin/env python3
"""Print compact project orientation for routine extraction runs."""

from __future__ import annotations

import argparse
from pathlib import Path
import sys

import yaml


ROOT = Path(__file__).resolve().parents[1]


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=ROOT)
    return parser.parse_args(argv)


def load_yaml(path: Path) -> dict:
    with path.open(encoding="utf-8") as handle:
        loaded = yaml.safe_load(handle) or {}
    if not isinstance(loaded, dict):
        raise ValueError(f"Expected mapping in {path}")
    return loaded


def line(label: str, value: object) -> str:
    return f"{label}: {value or 'missing'}"


def render(state: dict) -> str:
    current = state.get("current_source_unit") or {}
    next_unit = state.get("next_source_unit") or {}
    indexes = state.get("indexes") or {}
    return "\n".join(
        [
            "# Project Brief",
            line("Mode", (state.get("project") or {}).get("mode")),
            line("Current", current.get("book")),
            line("Chapter", current.get("chapter_title")),
            line("Pages", f"{current.get('page_start')}-{current.get('page_end')}"),
            line("Text", current.get("extracted_text_path")),
            line("Output", current.get("output_yaml")),
            line("Next unit", next_unit.get("chapter_title")),
            line("Duplicate index", indexes.get("duplicate_index")),
            line("Tag index", indexes.get("tag_index")),
            "Next command: just extract-current",
            "Lookup: just query-dupes <tag> <tag>",
            "Validate: just post",
        ]
    )


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)
    state = load_yaml(args.root / "project-control" / "processing-state.yaml")
    print(render(state))
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""Extract the current source unit described by processing-state.yaml."""

from __future__ import annotations

import argparse
from pathlib import Path
import subprocess
import sys

import yaml


ROOT = Path(__file__).resolve().parents[1]


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=ROOT)
    return parser.parse_args(argv)


def load_yaml(path: Path) -> dict:
    with path.open(encoding="utf-8") as handle:
        loaded = yaml.safe_load(handle) or {}
    if not isinstance(loaded, dict):
        raise ValueError(f"Expected mapping in {path}")
    return loaded


def require(unit: dict, key: str) -> object:
    value = unit.get(key)
    if value in (None, ""):
        raise ValueError(f"current_source_unit.{key} is required")
    return value


def build_command(root: Path) -> list[str]:
    state = load_yaml(root / "project-control" / "processing-state.yaml")
    unit = state.get("current_source_unit") or {}
    if not isinstance(unit, dict):
        raise ValueError("current_source_unit must be a mapping")

    return [
        sys.executable,
        str(root / "scripts" / "extract_pages.py"),
        "--pdf",
        str(root / str(require(unit, "source_file"))),
        "--start-page",
        str(require(unit, "page_start")),
        "--end-page",
        str(require(unit, "page_end")),
        "--output",
        str(root / str(require(unit, "extracted_text_path"))),
    ]


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)
    command = build_command(args.root)
    completed = subprocess.run(command, check=False)
    return completed.returncode


if __name__ == "__main__":
    raise SystemExit(main())
```

```python
#!/usr/bin/env python3
"""Check that hot runtime context stays compact and pointer-first."""

from __future__ import annotations

import argparse
from contextlib import redirect_stdout
import io
from pathlib import Path
import re
import sys

from scripts import project_brief


ROOT = Path(__file__).resolve().parents[1]

HOT_FILE_LINE_LIMITS = {
    Path("docs/instructions/runtime-contract.md"): 140,
    Path("project-control/next-run.md"): 45,
}

BRIEF_LINE_LIMIT = 20
TOTAL_CONTROL_LINE_LIMIT = 205

FORBIDDEN_POSITIVE_READS = [
    re.compile(pattern, re.IGNORECASE)
    for pattern in [
        r"\bread\s+appendix/generated/",
        r"\bread\s+appendices\b",
        r"\bopen\s+full\s+index\s+files\b",
        r"\bread\s+all\s+prior\s+chapter\s+yaml\b",
        r"\bread\s+chapters-index\.md\b",
        r"\bread\s+docs/instructions/archive/",
        r"\bread\s+project-control/archive/",
    ]
]

NEGATION_MARKERS = [
    "do not read",
    "only for human-facing",
    "not routine extraction",
    "not during normal runs",
]


def parse_args(argv: list[str] | None = None) -> argparse.Namespace:
    parser = argparse.ArgumentParser(description=__doc__)
    parser.add_argument("--root", type=Path, default=ROOT)
    return parser.parse_args(argv)


def nonempty_line_count(text: str) -> int:
    return sum(1 for line in text.splitlines() if line.strip())


def is_negated(line: str) -> bool:
    lowered = line.lower()
    return any(marker in lowered for marker in NEGATION_MARKERS)


def check_forbidden_reads(rel_path: Path, text: str) -> list[str]:
    errors = []
    for line_number, line in enumerate(text.splitlines(), start=1):
        if is_negated(line):
            continue
        for pattern in FORBIDDEN_POSITIVE_READS:
            if pattern.search(line):
                errors.append(
                    f"{rel_path.as_posix()}:{line_number} contains broad positive read: {line.strip()}"
                )
    return errors


def check_file(root: Path, rel_path: Path, line_limit: int) -> tuple[int, list[str]]:
    path = root / rel_path
    if not path.exists():
        return 0, [f"Missing hot file: {rel_path.as_posix()}"]
    text = path.read_text(encoding="utf-8")
    line_count = nonempty_line_count(text)
    errors = []
    if line_count > line_limit:
        errors.append(
            f"{rel_path.as_posix()} has {line_count} nonempty lines; limit is {line_limit}"
        )
    errors.extend(check_forbidden_reads(rel_path, text))
    return line_count, errors


def render_brief(root: Path) -> str:
    stdout = io.StringIO()
    with redirect_stdout(stdout):
        exit_code = project_brief.main(["--root", str(root)])
    if exit_code != 0:
        raise RuntimeError(f"project_brief exited with {exit_code}")
    return stdout.getvalue()


def check_brief(root: Path) -> tuple[int, list[str]]:
    text = render_brief(root)
    line_count = nonempty_line_count(text)
    errors = []
    if line_count > BRIEF_LINE_LIMIT:
        errors.append(f"just brief output has {line_count} nonempty lines; limit is {BRIEF_LINE_LIMIT}")
    errors.extend(check_forbidden_reads(Path("just brief"), text))
    return line_count, errors


def main(argv: list[str] | None = None) -> int:
    args = parse_args(argv)
    errors: list[str] = []
    total_lines = 0
    try:
        for rel_path, line_limit in HOT_FILE_LINE_LIMITS.items():
            line_count, file_errors = check_file(args.root, rel_path, line_limit)
            total_lines += line_count
            errors.extend(file_errors)
        brief_lines, brief_errors = check_brief(args.root)
        total_lines += brief_lines
        errors.extend(brief_errors)
    except Exception as exc:
        print(f"check_hot_context.py: error: {exc}", file=sys.stderr)
        return 1
    if total_lines > TOTAL_CONTROL_LINE_LIMIT:
        errors.append(
            f"hot control context has {total_lines} nonempty lines; limit is {TOTAL_CONTROL_LINE_LIMIT}"
        )
    for error in errors:
        print(error)
    return 1 if errors else 0


if __name__ == "__main__":
    raise SystemExit(main())
```

## Operating Rule After This Plan Lands

Routine extraction runs should use this command sequence:

```bash
just brief
just extract-current
just query-dupes <tag> <tag>
just post
```

To continue in the same session after the current source unit is complete and `just post` passes, run:

```bash
just advance-current
just brief
just extract-current
```

Use `just search "pattern"` only for targeted lookup. Open historical YAML files only when `just query-dupes` or `just query-entries` returns a likely match. Open full schema or background docs only when validation fails or classification is ambiguous.

## Expected Token Impact

The improvement comes from removing repeated orientation and command-construction tokens, not from the existence of `just` alone. After these tasks, a routine run should spend almost all context on:

- the compact runtime contract.
- the compact brief.
- current chapter text.
- current output YAML.
- a few query results and only the specific historical YAML files they identify.

The project keeps the full record; the agent reads pointers first and follows them only when needed. This should make same-session continuation realistic while preserving the current extraction quality gates.
